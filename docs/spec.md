# Pocket Picture Workshop — bounded specification

Recommended defaults accepted by the task: no optional interview. Grill with Docs decisions resolved through original-game evidence and user constraints.

Build an original pocket cartoon studio about Pip the seed courier and Moth the stage magician preparing the Moonseed Festival. Two actor/prop slots; three scenery choices; stand/walk/jump/wave/spin actions; per-frame placement and velocity; film replaces the selected actor's subsequent cues; rewind to layer the second actor. One cartoon has one backdrop. A new backdrop starts a fresh cartoon after explicit in-app confirmation. Canned original captions and synthesized cue sounds. Fixed 12 fps, adjustable 2–20 second length. Camera follows the mean actor position inside a wider bounded world. No platform collisions, drawing tools, uploads, or proprietary assets.

Public test seams: immutable authoring/model operations and normal visible browser controls including save/reload. These follow the user's explicit request for real authoring/playback state tests. Test keyframe boundaries, actor independence, overwrite semantics, camera clamping, invalid saves, pause/resume/end/edit, scene reset and persistence.

Modern conveniences: local autosave plus explicit save, editable numeric timing and coordinate fields, visible cue list, pause and seek. Simplifications: no exact NES memory/frame limits, gamepad interface, visual effect catalogue or VCR recording; captions are timed overlays rather than pauses; velocities expressed per frame. Artwork, story and synthesizer tones are original.
